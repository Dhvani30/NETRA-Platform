## Questions where code does not establish the intended meaning

1. Should the walkthrough state that the sentiment chart and alert sentiment thresholds use top-level `sentiment_label`, while the analytics pipeline writes sentiment under `ai_analysis.sentiment_label`? The current code does not show where/when top-level labels are populated.
2. Is the mutation timeline intentionally four equal-sized chronological slices? The README describes phase-by-phase volume changes over time, but implementation phases are count quartiles rather than fixed time windows.
3. Should “Community Clusters” be presented as node-type counts? The UI wording implies detected communities, while the API groups by Neo4j label; no community-detection algorithm is returned there.
4. Should Bridge Nodes be explained using the current neighbor-label-pair score and fallback, or is there an intended graph-theoretic bridge metric?
5. Are the demographics intended as explicitly illustrative heuristics? Current language values are assigned from total post count (not language detection), and age brackets infer age solely from platform or text length.
6. What are the intended live source coverage and refresh semantics? The repository includes a Reddit collector, graph builder supports Reddit/X/Telegram, while README also claims YouTube and real-time analytics. UI pages largely load once; Alerts alone polls every 30 seconds.
7. Which audience should the series address (analysts, policy/intelligence teams, developers, or general viewers)? Code describes analyst decisions generally but does not define intended user roles.
