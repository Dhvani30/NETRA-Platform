# NETRA Visual Identity

Use the active React application as visual source of truth. The composition is a faithful, sanitized reconstruction of its Analytics screen, not the separate `design-source` prototype.

## Colors
- Background: `#08091a` (active dashboard foundation also uses `#0a0a0f`)
- Raised surfaces: `#11122a`
- Accent: `#9a9ee8`; bright `#b8bbee`; dim `#7b7fc4`
- Primary text: `#f2f3fa`; muted: `#8e92b0`
- Sentiment accents: green `#70a888`, red `#c07070`, amber `#c09060`; blue `#7090cc`
- Borders: translucent white at about 10–14%; use a restrained localized lavender glow.

## Typography
- Space Grotesk for headlines and UI body text.
- JetBrains Mono for status labels, timestamps and compact metric names.

## Composition rules
Keep surfaces low-contrast and glass-like, with strong legibility. Do not use vivid cyan, invented chart numbers, real account handles, or mock-only product claims. Any illustrative chart data must be marked as a sanitized visual sample.
